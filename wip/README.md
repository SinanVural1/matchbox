# Work in progress

These shaders are **unfinished**. They were written before the rest of this repository and haven't been brought up to its current standard yet. Some may load in Flame with missing tooltips or rough controls, and none has a download page, preview icon or ZIP.

Use them at your own risk. The finished, tested shaders are in [`shaders/`](../shaders).

| Shader | What it does |
|---|---|
| [sv_Directional_Blur](sv_Directional_Blur) | Directional blur with falloff, limited by a matte |
| [sv_Hexagon_Mosaic](sv_Hexagon_Mosaic) | Honeycomb mosaic with rotation and luma scaling |
| [sv_Hypot](sv_Hypot) | Two-input hypot blend with strength |
| [sv_Lightning](sv_Lightning) | Animated lightning bolt with branches and a width curve |
| [sv_Polyhedra](sv_Polyhedra) | 3D regular polyhedra renderer. Based on a Shadertoy shader and not covered by the MIT License; see [LICENSE](../LICENSE). |
| [sv_Promist](sv_Promist) | Pro-Mist filter emulation |

When a shader here is finished, it moves to `shaders/` with its own page.
